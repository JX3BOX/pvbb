# 团队模块 2026-08-02 变更记录

本文记录 2026-08-02 团队模块前后端集中修复后的当前合同。长期业务结构仍以 [team.md](./team.md) 为准；Go 后端遗留问题与修复证据见 [team-go-fix.md](./team-go-fix.md)。

## 1. 涉及仓库

| 仓库 | 分支 | 主要范围 |
| --- | --- | --- |
| `frontend/pvbb` | `dev` | 团队工作台、公开主页、成员、视频、快照、DKP |
| `backend/jx3box-team` | `master` | 成员管理权限、正式成员查询、视频管理权限和视频归属保护 |
| `backend/service-cms` | `master` | 快照 API、DKP 权限/事务/考勤、数据库迁移 |

## 2. 前端变化

### 团队工作台与主页

- 管理路由与成员路由继续共用 `ViewMyOrg.vue`，无权限或非成员访问成员工作台时转到公开团队主页。
- 一级页签使用 `tab`，二级页签统一使用 `subtab`；成员审核、团队设置、快照和 DKP 均支持刷新恢复。
- 管理头部只显示团队身份与“团队主页”入口；公开好评、加入等操作只保留在公开主页。
- 公开主页页签调整为“团队概况 / 团队成员 / 团队活动 / 通关视频 / 留言板”，移除公开 DKP 页签。
- 团队海报改为 920 × 120 横幅，宽屏靠右展示，移动端隐藏背景图。
- 新建或编辑团队时 `v_dkp` 固定为成员可见级别 `2`，不再由档案表单单独选择。

### 成员与视频

- 加入申请的批准/拒绝按当前团队和 `role_id` 移除本地项，避免分页索引变化导致误删。
- 正式成员页继续按账号聚合角色；自定义角色能否返回由 Go 后端统一修复。
- `r_video` 管理员获得完整视频管理能力；公开视频和管理视频接口明确分离。
- 视频列表、事件列表以及增删改失败均有显式恢复逻辑，不再因请求失败残留 loading。

### 快照

- 前端快照服务全部迁到 `/api/cms/team/snapshot/...`。
- 团队成员工作台增加只读快照入口；管理入口可创建、编辑、删除并配置密码。
- 列表、卡片、统计、编辑和相关快照详情统一更新；详情弹窗支持分页和五队阵容预览。
- 编辑仅提交允许字段，并使用请求版本防止旧响应覆盖新记录。
- 快照关联 DKP 改用 `PUT /api/cms/team/dkp/:teamId/snapshot/:snapshotId`。

### DKP

- 管理区二级页签为“当前分值 / 历史记录 / 快照关联 / 高级操作”。
- 高级操作仅向创始人展示，重置使用危险操作说明和二次确认。
- 帮助文档入口与二级页签并列；DKP 表格、弹窗和日志统一团队工作台视觉。

## 3. Go Team 后端变化

### 成员管理

- 成员管理 GET 路由改用严格权限中间件，不再因为历史快照兼容逻辑跳过 GET 权限检查。
- 审核 action 只允许合法状态值；成员星级限制在 0～5。
- 正式成员候选查询补齐 `relation.status=1`。
- 有效角色条件统一为 `role.status=1 OR role.custom=1`，确保已通过的历史自定义角色进入账号的 `roles[]`。

### 视频管理

- `/video/team/:id/all` 允许创始人、`r_video` 管理员和系统管理员读取。
- PUT 更新先读取原视频，并强制保留数据库中的 `team_id`，阻止通过 payload 跨团队转移视频。
- 旧的“只有创始人可更新”控制被统一权限检查替代。

## 4. CMS 后端变化

### 快照 API

- 新增快照 model、service、controller 和 route，接口前缀为 `/api/cms/team/snapshot`。
- 管理权限：系统管理员、团队创始人或 `r_snapshot`。
- 读取权限：上述管理者或团队正式成员。
- 删除为软删除；列表和详情只返回有效记录。

### DKP

- 读取统一执行 `v_dkp` 可见性判断；团队管理员和创始人可直接读取。
- 普通 DKP 写入要求创始人或 `r_dkp`，重置只允许创始人。
- 分数与日志使用事务写入，并校验账号/角色确实属于当前团队。
- 快照考勤按角色 ID、游戏 ID 或唯一角色名匹配团队正式成员；无法安全关联的名单项跳过。
- 快照同步完成后写入 `dkp=1`，重复请求返回冲突。
- 新增 `20260802_harden_team_dkp.sql`，用于唯一约束、默认值和操作人审计字段。
